HTTP request arrives, hits Security Filter Chain
Spring Security decides where to let it go through or not
If allowed, DispatcherServlet looks at the URL (/register) and the HTTP method (POST) and finds the right Controller
Spring sees @RequestBody, calls Jackson -> Jackson translantes the raw JSON, creates the DTO object -> fills in the         object with data from that JSON
Spring validates (@Valid) the object by checking annotations in the DTO, if no field fails, lands it to the Controller


HTTP Request (Raw bytes)
Spring Security Filters (Bouncer)
DispatcherServlet (Router)
Jackson ObjectMapper (DTO Creation/Translation)
Hibernate Validator (@Valid check)
Controller Method (Your code starts here!)
